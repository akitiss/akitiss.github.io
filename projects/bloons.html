Recreation of the popular game Bloons TD5. Interactive game hosted in Processing and organized using multiple classes. Gameplay includes button‑based interactions and drag‑and‑drop mechanics that let the player position monkeys strategically. Each monkey type has some unique behavior and can be upgraded. Bloons follow a predefined path, with both the pathing and attack patterns fully coded. The game currently features four monkey types and includes a freeplay mode.
