Interactive web application built using Flask and JavaScript, with Bootstrap providing the visual styling. The site teaches users the basics of color theory through guided, interactive lessons and interactive quizzes. The interface is created with HTML and CSS to ensure a clean, responsive user experience. All data is stored in JSON, and the pages use templating to efficiently load and organize content.
