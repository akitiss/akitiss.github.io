Interactive Notepad

Website hosting virtual notepads where users can create, edit, and delete as many notepads as they want. Each notepad supports post‑its that users can freely add and modify, as well as a drawing feature that can be cleared at any time. Built using JavaScript, HTML, and a Flask‑based backend, with data stored in a database to keep everything consistent across sessions.
