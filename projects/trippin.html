Trippin

App that helps plan a trip based on user‑selected preferences. Users can choose locations, desired activities, and other inputs, and the app automatically generates a day‑by‑day itinerary. Users can freely edit activities after the schedule is created. Completed trips are saved to the user database, where they can be viewed or modified at any time. Built using APIs, a Flask server, HTML templates, Python, and SQLite3. When a user creates a trip, the server requests information from external APIs and displays it through HTML templates. Saved trips are stored in the SQLite database and used by the program to load and present past or ongoing itineraries.
